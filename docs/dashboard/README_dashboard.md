# Dashboard – Hav og vind

Legg dashboard-filer her (utenfor `custom_components/`).

## Anbefalt oppsett

- Dashboardet peker på proxy-entiteter (faste entity_id-er).
- Du velger aktiv stasjon i dropdown **Hav & Vind – Aktiv stasjon**.
- Når du legger til nye stasjoner, trenger du ikke endre dashboardet – bare velge stasjon i dropdown.

## Filer

- `Dashbord.js` – dine eksisterende dashboard-notater/byggfil (flyttet hit for å holde integrasjonen “ren”).
- `lovelace_hav_og_vind.yaml` – (valgfritt) lim inn ferdig view/dashboard-YAML her.
